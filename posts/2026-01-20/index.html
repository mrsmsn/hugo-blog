キーボードの利用状況分析（ヒートマップ・ショートカットの利用率等）

2026/01/20 · 4645 文字

背景・動機#

一言で言うと、愛用している自作キーボードの Keyball39 / cool642tb のキーマップを変更したくなった。

キーマップは最初に設定してほとんど変えてこなかったのだが、半年前に仕事に復帰して本格的に使うようになったら細かいところでモヤモヤしてきて、本格的に見直そうとなった。

そんなところに、「A,S,D,FキーにShiftやCtrlキーを割り当ててしまおうぜ」っていうやや狂った Home Rod Mods と偶然出会い試したのだが、かなり悪戦苦闘し、こりゃ真面目に考えないといけないなーとなり、そもそも自分はどのキー / ショートカットに依存しているかを洗い出したくなったのだった。

検証#

方法#

whatpulse.org のMacデスクトップ用アプリを入れて検証。 結果をcsvエクスポートができるので、出力内容をduckDBでいい感じに見る。

キーロガー系のアプリはセキュリティ的な心配はあるので次を徹底。

  • アプリの使用中はパスワード・個人情報の類は入力しない
  • 検証が終了したらアプリを終了。Mac上の入力監視の権限をOffにする

使用環境#

次の作業・環境下で4時間程度利用してみた。

作業内容#

  • Chromeでブラウンジング
  • Obisidianでかなりメモ
  • Terminal（Ghostty）もちょこっと。なお、プログラムは書いていない

  • ctrl + W : cli上でword単位で削除。スペースなくても単語で消してくれるzshは偉い
  • ctrl + T : tmux のprefix-key（途中まで）

上位に出てこなかった好きなショートカット#

  • Command + P : コマンドパレット系が上位になかったのが意外
  • Command + Z : 多動症的としてはundoは絶対多用しているけど、vimだと「u」だけだから結果に出てなさそう
  • Ctrl + Space : Raycast(コマンドパレット型のランチャー) の起動
