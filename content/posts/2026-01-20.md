## 背景・動機

一言で言うと、愛用している自作キーボードの [Keyball39](https://shirogane-lab.net/items/64b8f8693ee3fd0045280190) / [cool642tb](https://booth.pm/ja/items/6740910?srsltid=AfmBOorKkGyatvrx92huwBB8VX77mSCSFix6cLJYxhhZe0C_IGBgSDtN) のキーマップを変更したくなった。

キーマップは最初に設定してほとんど変えてこなかったのだが、半年前に仕事に復帰して本格的に使うようになったら細かいところでモヤモヤしてきて、本格的に見直そうとなった。

そんなところに、「A,S,D,FキーにShiftやCtrlキーを割り当ててしまおうぜ」っていうやや狂った [Home Rod Mods](https://precondition.github.io/home-row-mods) と偶然出会い試したのだが、かなり悪戦苦闘し、こりゃ真面目に考えないといけないなーとなり、そもそも自分はどのキー / ショートカットに依存しているかを洗い出したくなったのだった。

## 検証

### 方法

whatpulse.org のMacデスクトップ用アプリを入れて検証。
結果をcsvエクスポートができるので、出力内容をduckDBでいい感じに見る。

キーロガー系のアプリはセキュリティ的な心配はあるので次を徹底。

- アプリの使用中はパスワード・個人情報の類は入力しない
- 検証が終了したらアプリを終了。Mac上の入力監視の権限をOffにする

- ctrl + N : next
- command + V : ペーストマン。yank-pasteが活躍しているためちょい低い

- ctrl + F : tmux のprefix-key（途中までTだった）
- ctrl + H : nvimやtmuxでwindow,paneを移動する
- ctrl + . : 記憶にないと思ったが「,」「.」がショートカット割り当たってないし、衝突しないし割り当てようとしてうまくできなかった実験結果だ
- ctrl + W : cli上でword単位で削除。スペースなくても単語で消してくれるzshは偉い
- ctrl + T : tmux のprefix-key（途中まで）

## 上位に出てこなかった好きなショートカット

- Command + P : コマンドパレット系が上位になかったのが意外
- Command + Z : 多動症的としてはundoは絶対多用しているけど、vimだと「u」だけだから結果に出てなさそう
- Ctrl + Space : Raycast(コマンドパレット型のランチャー) の起動
